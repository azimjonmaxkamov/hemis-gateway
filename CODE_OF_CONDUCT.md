# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, welcome newcomers, assume good intent, and never harass anyone.
Unacceptable behaviour may be reported to the maintainer, Azimjon Makhkamov (raqamlivodiy@gmail.com).
Reports are handled confidentially.
