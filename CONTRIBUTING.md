# Contributing

Thank you for helping universities integrate with HEMIS safely!

1. Fork the repository and create a feature branch.
2. Install dependencies: `pip install -r requirements.txt pytest pytest-asyncio`.
3. Run the tests: `pytest -q tests` — all tests must pass; add tests for new behaviour.
4. Keep the SPDX header (`SPDX-License-Identifier: Apache-2.0`) and the original copyright notice in every file.
   You may add your own copyright line for substantial changes.
5. Never include real tokens, keys or personal data (students, staff) in code, tests, issues or screenshots.
6. Open a pull request describing the change and its security impact.

By submitting a contribution you agree that it is licensed under the Apache License 2.0 (Section 5 of the license).
