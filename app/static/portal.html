Kalit yuborish

Backend API endpointlari uchun HEMIS dagi kabi Authorization: Bearer hg_… ham ishlaydi. Talaba/Tutor API da esa Authorization ga talaba tokeni, kalit esa X-Gateway-Key ga yoziladi.
